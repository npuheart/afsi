# demo_802 — 剪切流中的液滴：Taylor 形变（**定性**）

方腔里施加**精确线性剪切** `u = (gdot (y - L/2), 0)`（四面壁都按该剖面给 Dirichlet，
它是 Navier–Stokes 的精确定常解，且速度在液滴中心为零，液滴不会漂移）。
液滴达到**倾斜椭圆的定常态**后，用 `phi >= 0.5` 区域的二阶矩取长短轴 `L`、`B`：

```
D = (L - B) / (L + B) ,     小 Ca 时 Taylor:  D = Ca (19 lambda + 16) / (16 lambda + 16)
Ca = mu_matrix gdot a / sigma ,   lambda = mu_drop / mu_matrix ,  倾角 -> 45 deg
```

这个算例同时检验**变黏度**通路（`mu(phi)` 每步重新装配矩阵）。

## 设置

* `NX = 64`、`R = 0.2`、`sigma = 0.1`、`mu_matrix = 0.05`、`lambda = 2`、`Ca = 0.1`
  （`gdot = Ca sigma / (mu_matrix R) = 1.0`）、`eps = h`、`M = 0.002`、`dt = 4e-4`、
  总应变 `gdot * t = 0.8`。

## 结果（实测）

| 量 | 测值 | 参照 | 比值 |
|---|---|---|---|
| 形变 `D` | **0.1718** | Taylor `0.1125` | **1.53** |
| 等效半径 `a_eq / R` | 1.0003 | 1（面积守恒） | ✓ |
| 倾角 | 38.2° | 45°（小 `Ca`） | 偏小 |

先前几组配置（同一代码，只改 `eps` 与液滴大小）：

| 配置 | `eps/h` | `4 eps / R` | `Ca` | `D` | Taylor | 比值 |
|---|---|---|---|---|---|---|
| `R=0.15, 48x48` | 1.5 | 0.42 | 0.045 | 0.0992 | 0.0506 | 1.96 |
| `R=0.15, 48x48`（`M` 小 10 倍） | 1.5 | 0.42 | 0.045 | 0.0997 | 0.0506 | 1.97 |
| `R=0.2, 64x64` | 2.0 | 0.62 | 0.10 | 0.2345 | 0.1125 | 2.08 |
| `R=0.2, 64x64` | 1.0 | 0.31 | 0.10 | 0.1969 | 0.1125 | 1.75 |
| `R=0.2, 64x64`（总应变 0.8） | 1.0 | 0.31 | 0.10 | 0.1718 | 0.1125 | **1.53** |

**比值随界面变薄（`eps = 2h -> 1h`）与液滴变大而单调下降**，说明主因是
**扩散界面厚度**（`4 eps` 与液滴半径同量级时"液滴"几乎全是界面）与
**有界域约束**（`a/H ~ 0.4`，剪切流中近壁液滴形变已知会增大），而不是求解器错误：

* 测得的**环境剪切率**是精确的：拟合 `du_x/dy = 0.60000`（施加 0.6），
  三处取样一致；速度场 `max|u| = gdot L / 2`。
* **测量方法本身已标定**：对精确椭圆相场（`D = 0.05 / 0.1 / 0.2`）反算得
  `0.0454 / 0.1126 / 0.2115`、倾角 45.0°，即测量误差 `±0.005`（`D` 的 10% 以内）。
* 同一套代码在 `demo_803`（无环境剪切、由界面自身曲率驱动）里把
  Maffettone–Minale 松弛时间算到 **6%** 以内，说明表面张力/黏性的**动平衡**是对的。

**能验证**：变黏度通路（面积守恒 `a_eq/R = 1.000`、矩阵每步重装正确）、
剪切率/速度场精确、液滴确实随 `Ca` 增大而形变、倾角接近 45°。

**不能验证**：`D` 的绝对值 —— 在本机可承受的网格（`NX <= 64`、`4 eps/R >= 0.3`）下
比 Taylor 大 1.5~2 倍，**没有收敛到解析值**。要定量验证需要同时满足
`4 eps << R`（=> `eps <= 0.25h` 或更细网格）与大域（`a/H < 0.2`），
即 `NX >= 128` 且域尺寸 `>= 4R`，单算例需要数小时；本次未做。
已知的第三个误差源是 Allen–Cahn **不守恒**（`M` 大时液滴会收缩，`a_eq/R` 掉到 0.92），
因此默认取小 `M = 0.002`。

## 运行

```bash
conda activate afsi-dolfinx
cd afsic/demo/multiphase/demo_802_shear_droplet

python main.py                                       # Ca = 0.05, lambda = 2, 64x64
python main.py --Ca 0.1 --R 0.2 --eps 1.0 --mobility 0.002 --strain 0.8 --plot
python main.py --sweep --plot                        # Ca = 0.025/0.05/0.1（每档约 3~20 min）
```

结果写到 `output/taylor.csv`（`--plot` 时另有 `output/taylor.png`：`D`-`Ca` 对比图）。
上表"总应变 0.8"那一行就是上面第二条命令，本机 **189 s**。
