# demo_474 — IB2d `Tracers_In_Bifurcating_Artery`（分叉动脉里的射流与示踪粒子）

IB2d 官方算例（`matIB2d/Examples/Example_Tracers/Tracers_In_Bifurcating_Artery`）。
`arb_ext_force` + 软钉死结构 + **378 个被动示踪粒子**。

## 算例内容

* `2 x 2` 周期盒、`mu = 0.1`、`rho = 1`、`128 x 128`、`dt = 1e-4`（官方）/ `5e-5`（本 demo）；
  官方 `T = 1.0`（10000 步），本 demo 默认 `T = 0.1`（2000 步）。
* **结构**：1144 个 `k = 1.2e7` 的钉死目标点描出一条 Y 形分叉动脉
  （主干沿 $x$、`y in [0.86, 1.14]`，两支沿 $y$ 展开），378 个示踪粒子。
* **外力**：主干内 `x in [0.1, 0.13]`、`y in [0.86, 1.14]` 的 `tanh(t)` 缓启抛物射流
  （`k = 1e4`、`u_max = 250`、`W = 0.3`）。

## 两个必须记录的问题

1. **dt 必须减半**。官方 `dt = 1e-4` 时，$k\,dt^2/(\rho h^2) = 0.49$，
   AFSI 的 Taylor–Hood 离散在 $t\approx0.005$ 就在某个标记点附近局部发散（NaN）；
   `dt = 5e-5`（该参数 0.12）两边都稳定。**本 demo 因此对两个代码都用 `dt = 5e-5`**（对比公平）。
2. **$\gamma$ 必须打开**。$\gamma = 0$ 时被驱动的射流比参考**大 1.5 倍**（比例随时间恒定，
   不是相位差）；扫描后 `GRAD_DIV = 1.0` 把窗口 `max|u|` 差降到 **2.7%**
   （$\gamma$=0/1/1.5/2.5 → 0.956/0.617/0.580/0.546，参考 0.635）。
   这是**散度误差**在"被壁面围住的射流"里的又一次体现（同 demo_451/473）。

另：本算例的顶点文件里有 **3 对坐标完全重合**的标记点（分叉汇合处），
IB2d 把它们当作不同拉格朗日点；AFSI 侧需要一个极小偏移（$10^{-6}h$）才能让
"标记点 ↔ 自由度"一一对应，`main.py` 里有说明。

## 结果（`dt = 5e-5`、`GRAD_DIV = 1.0`，11 帧，末帧 `t = 0.1`）

| 指标 | 结果 |
|---|---|
| 施力窗口 `max|u|` AFSI / IB2d | 1.2292 / 1.2628（**2.7%**） |
| 标记点偏差（1144 点钉死） | 1.63e-4 m = **1.0e-2 h** |
| 378 个示踪粒子 `max|ΔX_t|` | 7.7e-3 m = **0.49 h** |
| 罚力公式核对 | ≤7.9（`\|f\|_{\max}` 1.7e4，**0.05%**） |
| 速度场相对 $L_2$ 误差（窄带外） | 5.5e-1 ✗ |
| 中列（$x = 1$）窗口行流量 | AFSI +0.0396 / IB2d −0.0197 ✗ |

**能验证**：驱动机制（窗口 2.7%、罚力 0.05%）、软钉死结构（1.0e-2 h）、示踪粒子平流（0.49 h）。
**不能验证**：分叉/分支区的流动结构——两边相差 $L_2$ 5.5e-1、中列流量甚至符号不同。
该区域由**软目标点壁的"渗漏"**主导（`k = 1.2e7` 的钉死壁不是严格不可穿透），
而共置 FFT 与 Q2/Q1 有限元对壁面渗透的离散描述不同；本 demo 把它作为已知局限记录，
不做"看起来接近"的粉饰。
