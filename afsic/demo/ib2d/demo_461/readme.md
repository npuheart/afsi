# demo_461 — IB2d `Single_Coral` (video-fit 弯曲运动目标点)

IB2d 官方算例（`matIB2d/Examples/Example_Corals/Single_Coral`）在 AFSI 中的复现。
锚点规律是**实验视频数据的多项式拟合**（弯曲模型），而非几何构造，是这批算例里
"最不像教科书"的一个。

## 算例内容

`0.6 x 0.6` 周期盒、`mu = 0.01`、`rho = 1`、`64 x 64`、`dt = 1e-5`。
结构是一条 **90 点珊瑚**（**两条触手，各 45 点**，位于 $x=0.3$ 两侧），
无弹簧无梁，每个点都是 `k = 1e8` 的目标点。

锚点规律（`update_Target_Point_Positions.m`）只驱动 **x**（y 保持在初始位置，
`.m` 里那行是注释掉的）：

$$X(y,t) = \text{xoffset} + q_4(t)/S - q_3(t)\xi + q_2(t)S\xi^2 - q_1(t)S^2\xi^3,\quad \xi = y - 0.25$$

其中 $q_1\ldots q_4(t)$ 是四条**五次多项式**（`.m` 里按**升幂**书写：
`qpoly1 = qc17 + qc16 t + ... + qc11 t^6`），自变量是视频帧号
$t = 30\,(\text{current\_time} \bmod 2.30)$；$S = 1733.33$ px/dm 是拟合时的
单位换算系数。第一条触手关于盒子中心镜像。当 $t > t_p = 67.5$ 帧时，多项式被
**线性过渡回 $t=0$ 的取值**，因此规律在整个 $2.30$ s 周期上连续，触手周期性
回到初始形线——**$t=0$ 的规律与 `coral.vertex` 逐位一致（1.67e-16 m）**。

> 上游小细节：`.m` 中的多项式系数是升幂排列（`qc*1` 乘 $t^6$、`qc*7` 是常数），
> 正好是 `np.polyval` 需要的降幂顺序，直接传整行即可（初版误用了 `[::-1]`，
> 结果出现 1e5 量级的假形变，已修正）。

## 缩减的运行时间

原算例 `Tfinal = 2.5 s`、`dt = 1e-5` ⇒ **25 万步**，本移植默认只跑
**$T = 0.115$ s（11500 步，约 0.05 个脉冲）**，`print_dump` 也从 2000 降到 250；
此时锚点已走出 **4.41 h** 的行程（$h = L_x/64 = 0.009375$）。作为补偿，
`compare.py` **解析地**验证了整个 $2.30$ s 脉冲的规律：全程行程 **6.00 h**、
周期性误差 **0.00e+00 m**、$t=0$ 复现 `coral.vertex` 到 **1.67e-16 m**。
即"规律的完整验证"不依赖缩减运行，缩减运行只限制了流固耦合被采样的时间长度。

## 结果

参考运行 15.3 s、AFSI 运行 127 s，两边各 47 帧：

| 指标 | 结果 |
|---|---|
| 标记点偏差 | 典型 **4.3e-6 m = 4.5e-4 h**，最大 **5.36e-6 m = 5.7e-4 h** —— 本批移动目标点算例中一致性最好的一个（运动慢：最大锚点速度 ~0.7 m/s，远低于 demo_459/460 的 20 / 7 m/s） |
| 形状质心 | 最大偏差 **1.0e-6 m** |
| x 方向展宽 | 预设 0.09730–0.17883 m；与预设之差 AFSI **1.4e-5**、IB2d 9.8e-6 m |
| 目标点递推 | 与 `.m` 规律**逐位一致**（1.67e-16 m） |
| 标记点-锚点滞后 | AFSI ≤ **2.0e-5 m**、IB2d ≤ 2.3e-5 m（两者几乎相同——因为运动慢，$k=10^8$ 罚力的柔度差异被淹没了；对比 demo_460 的 5.4e-3 vs 1.95e-2 m） |
| 速度场 | 全程 `max|u|` AFSI 0.891 / IB2d 1.082 m/s，末帧 `max|Δu|` 0.109 m/s |

结论：**慢速、大范围、数据驱动的移动目标点在 AFSI 中复现到 1e-4 h 量级**。
与 demo_460 对照可以得到一条有用的经验：罚力柔度误差正比于锚点速度
（20 m/s → 1e-2 h；7 m/s → 0.4 h；0.7 m/s → 5e-4 h），因此在"结构运动学被
指定"的算例里，标记点逐点一致性由**结构速度**决定，而不是网格或时间步。

## 移植要点

1. `matIB2d` 的 1-based 文件 → `ib2d_io.load_example(..., index_base=1)` 重编号，
   `run_reference.py` 写出重编号后的 `.target`。
2. 参考运行目录还需要 `.m` 的 Python 移植（pyIB2d 从运行目录 import）。
3. 结构用**两条独立**的零刚度 FE 链（各 45 点，不闭合）承载标记点自由度。
4. 输出帧与 pyIB2d 落在**同一步**（上游时间戳晚一步的约定同 demo_459/460）。

## 运行

```bash
conda activate afsi-dolfinx
python run_reference.py          # pyIB2d 参考 -> ib2d_reference.npz（~15 s）
python main.py                   # AFSI        -> plot/afsi_result.npz（~130 s）
python compare.py                # 对比 + figures/
```

环境变量：`TFINAL`（默认 0.115）、`DT`、`NX`、`PRINT_DUMP`（默认 250）、
`GRAD_DIV`、`OUTPUT_PATH`；参考脚本选项：`--tend`、`--dt`、`--print-dump`、
`--out`、`--run`。`TFINAL=0.002 PRINT_DUMP=50 python main.py` 可做 smoke test。
