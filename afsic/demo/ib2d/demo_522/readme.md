# demo_522 — IB2d 水母收敛阶梯 `Re75/Res_64_80x24`（结构分辨率 × Reynolds）

IB2d 官方算例（`matIB2d/Examples/Examples_Education/Convergence/Jellyfish/Simulation_Skeletons/Re75/Res_64_80x24`，上游 gitignored）：
`ib2d_input/` 是该目录 `input2d` / `jelly64.vertex` / `jelly64.spring` /
`jelly64.nonInv_beam` / `jelly64.target` 的逐字拷贝。

这是 **Hoover & Miller (2015) 水母模型**（Battista 的 IB2d 版本）**收敛性阶梯**
中的一格：上游把同一套几何按结构分辨率 `Res`（钟形 Lagrangian 间距
`ds_struct = 8/Res = 0.125` m）和 Reynolds 数
`Re = ρUL/μ ∈ {37.5, 75, 300}`（目录名给的 Re；若取 `U = 0.1` m/s、`L = 10` m
（域高）则 `ρUL/μ = 1000·0.1·10/13.333 = 75`，与目录名一致）
展开成 3 × 11 = 33 个骨架目录。**本 demo 是其中一格**，
`ib2d_input/` 即该格的原始几何与输入。

## 算例内容

* 周期盒 `[0,3] × [0,10]`、`ρ = 1000`、`μ = 13.333`、`supp = 4`；
* **钟形**：`Make_Jelly_Geometry.m` 生成的水母截面（半椭圆 `a = 0.5`、`b = 0.75`，
  下端截到 `d = -0.25`），平移到中心 `(1.5, 2.0)`；
* **本格结构**（`main.py` 打印的实测值）：

  ```
  structure    : 59 markers, 42 springs (k=1.6e+08, alpha=1..1), 37 non-invariant beams (kb=1.02e+09), 12 target points (k=2.5e+06)
  ```

  即 **59 个标记 / 42 根弹簧**（钟形轮廓 `k = 10^7/ds`；其中
  **4 根"肌肉"弹簧** `k = 10^5`、**静长 0**，连接钟形两只"下翼"）/
  **37 根非不变梁** / **12 个目标点**（顶边一排 flow blocker，
  `k_t = 2.5e6`，钉在初始位置）；
* **驱动**：`update_Springs.m`（→ `ib2d_input/update_Springs.py`）每步把肌肉块的
  静长设成 `L_i(t) = |cos(freq·π·t)|`、`freq = 1.0 Hz`，于是肌肉在
  `t = 0, 1, 2, …` 伸到 1、在 `t = 0.5, 1.5, …` 缩到 0：**每 1 s 一次
  "收缩—回弹"**（`abs()` 把负半周期镜像了，上游注释 "not 2*pi*f*t b/c of abs()"
  说的就是这件事）。

## 移植要点

### 1. 上游 bug：`springs_info(39:end,4)` 的行范围是错的（本批的核心发现）

骨架里 `update_Springs.m` 的唯一有效行是 `springs_info(39:end,4) = abs(cos(...))`。
这个 `39` 是从**真能跑的** `Example_Jellyfish_Swimming/Hoover_Jellyfish` 抄来的
（那里钟形有 318 根弹簧、肌肉块是 `319:357`，即 39 根肌肉）；而本阶梯的 `.spring`
把钟形弹簧放在**前面**、肌肉块放在**最后**，于是 `39:end`：

| Res | 弹簧总数 | 肌肉行（真值，1-based） | `39:end` 命中 | 后果 |
|---|---|---|---|---|
| 32 | 20 | 19–20 | 空 | **完全不激活**（水母不动） |
| 48 | 31 | 29–31 | 空 | **完全不激活** |
| 64 | 42 | 39–42 | 39–42 | **恰好正确**（钟形只有 38 根） |
| 96 | 65 | 59–65 | 39–65 | 多改 20 根钟形弹簧 |
| 192 | 132 | 119–132 | 39–132 | 多改 80 根 |
| 1024 | 715 | 637–715 | 39–715 | 多改 636 根 |

**本格**：`Res_64`，弹簧 42 根，肌肉块 = 第 39–42 行，
而 `39:end` 命中 `39–42`。

钟形弹簧的静长等于标记间距 `ds`，被改写成 `|cos| ≤ 1` 后相当于拉伸
`1/ds` 倍。用**逐字**规则实测（demo_521，`JELLY_MUSCLE_ROWS=verbatim`）：
AFSI 在 `t = 6e-3` 变 NaN、pyIB2d 在 `t = 8e-3` 变 NaN —— 两边都炸，
比较无意义，所以逐字规则不能作为 demo 的默认行为。

另外，上游这份骨架**从未跑通过**：`Res_1024_1280x384/job.96511.out` 里
2018-08-31 的作业日志是
`Error: Function definitions are not permitted in this context.`
（`submit.sh` 用 `matlab -nodisplay < main2d.m` 把函数文件当脚本喂了进去）。

### 2. 本 demo 的做法（恢复上游"原意"，与内部一致）

生成器把肌肉弹簧的静长**存成 0.0**（其余弹簧的静长等于初始距离），所以
`ib2d_input/update_Springs.py` **只更新 `L0 == 0` 的肌肉块**——语义上等于
`Hoover_Jellyfish` 的 `springs_info(319:357,4)`、`Tentacle_Jelly` 的
`starting_muscle = 318+1`，即"只驱动肌肉、不动钟形轮廓"。其余逻辑逐行照抄。
`JELLY_MUSCLE_ROWS=verbatim` 可切回上游 `39:end` 行为；由于 AFSI 与 pyIB2d
**共用同一份模块**，切回去两边仍然是一致地炸。

### 3. 减缩设置（本批 27 个 demo 用的公共设置）

上游这一格用**方形网格** `Nx = 0.375·Res = 24`、`Ny = 1.25·Res = 80`
（`dx = dy = 8/Res = 2·ds_struct`）、`dt = 1e-5`、`Tfinal = 5` s
（**500 000 步**）、`print_dump = 5000`，并为它准备了 15 天墙钟预算的 Slurm 脚本。
本批把阶梯统一压到一个可跑的公共设置（阶梯的意义就是"同一设置下比较不同格"）：

| | 上游（本格） | 本 demo（公共设置） |
|---|---|---|
| 网格 | 24 × 80（dx = dy = 0.125） | **36 × 120**（dx = dy = 1/12） |
| dt | 1e-5 | **1e-4**（10×） |
| Tfinal | 5 s（500 000 步） | **0.25 s**（2500 步） |
| print_dump | 5000 | 125（21 帧） |

公共网格 36×120 正是 **Res_96 那一格的上游网格**（阶梯中位数），此时
`ds_code = Lx/(2Nx) = 1/24 = 0.041667`，对 Res_96 的结构间距 0.041667 恰好匹配；
其余格则偏粗或偏细（本格 64：`ds_struct = 0.125`，
`ds_code/ds_struct = 0.333`）⇒ 结构力的 `ds` 权重被
系统性地高估/低估。两个代码用的是同一条公式（`ds = Lx/(2Nx)`），所以**两边仍然可比**，
但**不能**当作上游那一格的真实解（见"不能验证"）。

**要把本格跑成上游设置**：用下面"运行"里第 3 段的命令（`NX=24 NY=80 DT=1e-5
TFINAL=5.0 PRINT_DUMP=5000`）。注意 `Res_1024` 那一格是 384×1280 = 491 520 个单元、
50 万步，本机不可行。

### 4. 机制来自合并模板

弹簧（线性/非线性）、非不变梁、目标点、每步更新静长全部走已合并的
`_template/main.py`（与 demo_445 的 Hoover 水母同源）；本 demo 没有外力模块
（`arb_ext_force = 0`），也没有标量/示踪粒子。

（表中 `h = Lx/NX = 1/12` 是 AFSI 网格间距，`dXmax/h` 是标记点最大偏差除以 `h`；
`max|u| a/r` = AFSI / IB2d；`relL2` 是窄带外速度场的相对 `L_2` 误差。）

**能验证**：肌肉驱动的"收缩—回弹"运动学——标记点轨迹、弹簧（轮廓 + 肌肉）的长度、
目标点约束、流场峰值速度量级都在同一条轨迹上。

**不能验证（如实记录）**：

* **上游那一格的真实解**：本 demo 用 36×120/`dt = 1e-4`/`T = 0.25 s`，
  与上游 24×80/`dt = 1e-5`/`T = 5 s` 不同；且上游那一格**从未跑通过**
  （见 §1），因此没有可比对的"官方结果"；
* **流场小尺度结构**（`relL2`、`max|du|` 那一列）：公共网格与结构间距不匹配，
  对高 Res 的结构（本格 64，间距 0.125 m）**欠分辨**；尾流涡结构本身
  在两个离散下也只能定性一致；
* **收敛阶**：收敛性研究需要同一 Re 下逐格跑上游网格，本 demo 只是其中一格。

## 运行

```bash
conda activate afsi-dolfinx
# 1) 参考（pyIB2d）→ ib2d_reference.npz（本机实测 2m8.585s）
python run_reference.py --nx 36 --tend 0.25 --dt 1e-4 --print-dump 125
# 2) AFSI → plot/afsi_result.npz（本机实测 5m28.555s）
TFINAL=0.25 PRINT_DUMP=125 NX=36 NY=120 DT=1e-4 python main.py
# 3) 对比表（figures/compare_table.csv）+ 图
python compare.py
```

切回上游本格设置（以 24×80、`dt = 1e-5`、`T = 5 s` 为例；本机不可行，
仅作说明）：

```bash
python run_reference.py --nx 24 --tend 5.0 --dt 1e-5 --print-dump 5000
TFINAL=5.0 PRINT_DUMP=5000 NX=24 NY=80 DT=1e-5 python main.py
# 复现上游 `39:end` 的爆炸行为（两边一致地 NaN）：
JELLY_MUSCLE_ROWS=verbatim python run_reference.py --nx 36 --tend 0.02 --dt 1e-4 --print-dump 100
JELLY_MUSCLE_ROWS=verbatim TFINAL=0.02 PRINT_DUMP=100 NX=36 NY=120 DT=1e-4 python main.py
```
