# demo_803 — 变形液滴的松弛：Maffettone–Minale 时间（**定量**）

把一个略呈椭圆的液滴（初始形变 `D_0`）放入静止方腔（四壁无滑移、无重力、无剪切），
它会松弛回圆形。黏性液滴在小形变下的线性理论（Taylor 1932；Cox 1969；
Maffettone & Minale 1998）给出指数衰减 `D(t) = D_0 exp(-t / tau)`，其中

```
tau = (R mu_matrix / sigma) * (2 lambda + 3)(19 lambda + 16) / (20 (lambda + 1)) ,
lambda = mu_drop / mu_matrix ,   R = 等效半径
```

这个算例与 `demo_802` 互补：**没有环境剪切、没有域约束与流动的耦合**，
驱动力完全来自界面自身的曲率，因此它直接检验"表面张力力 ↔ 黏性耗散"的
**动平衡**——这正是两相求解器最核心的部分——以及**变黏度**（`lambda`）通路。

## 设置

* `NX = 64`、`R = 0.25`、`sigma = 0.1`、`mu_matrix = 0.05`、`eps = h`、`dt = 2e-4`、
  `D_0 = 0.1`、`M = 0.005`（小 `M`：Allen–Cahn 不守恒，`M` 大会让液滴在松弛的同时收缩）。
* 初始相场由椭圆（长短半轴 `a = R sqrt((1+D_0)/(1-D_0))`、`b = R sqrt((1-D_0)/(1+D_0))`、
  `ab = R^2` 保面积）的符号距离场生成，`Tfinal = 1.8 tau`。
* `D(t)` 由 `phi >= 0.5` 区域二阶矩的长短轴给出（该测量方法对精确椭圆标定过：
  `D = 0.05 / 0.1 / 0.2` 反算 `0.0454 / 0.1126 / 0.2115`，误差 `±0.005`），
  对 `ln D` 做最小二乘拟合得到 `tau_measured`。

## 结果（`--sweep`，本机实测）

| `lambda` | `tau` 理论 | `tau` 实测 | 比值 | 末态 `D` | 步数 | 用时 |
|---|---|---|---|---|---|---|
| 0.5 | 0.4250 | **0.5000** | 1.176 | 0.0268 | 3825 | 343 s |
| 1.0 | 0.5469 | **0.5683** | 1.039 | 0.0200 | 4920 | 246 s |
| 2.0 | 0.7875 | **0.7426** | 0.943 | 0.0164 | 7380 | 672 s |

* 三个 `lambda` 的松弛时间都在解析值 **6%~18%** 以内，而且**随 `lambda` 的变化趋势**
  正确（理论 0.425 / 0.547 / 0.788，实测 0.500 / 0.568 / 0.743）——
  这同时定量验证了**黏度跳变**（`mu(phi)` 每步重装）的实现。
* 松弛曲线在对数坐标下是直线（`output/relaxation.png` 里与解析虚线重合），
  即确实是单一指数衰减，没有伪模态。
* 残余偏差的来源：界面厚度 `4 eps = 0.0625 = R/4`（扩散界面的等效表面张力略低于 `sigma`，
  `demo_801` 里该效应给出 `dp` 偏高 1.7%，即 `sigma_eff ~ 1.02 sigma`），
  以及 `dt` 一阶的投影分裂误差。

**能验证**：表面张力与黏性耗散的动平衡（松弛时间）、黏度比 `lambda` 的影响、
液滴形状测量方法本身（对精确椭圆标定）。

**不能验证 / 局限**：`4 eps / R = 0.25` 时的偏差（最大 18%）；由于 `eps` 不能小于
`0.75h`、`R` 又受网格分辨率约束，本次没有做 `eps -> 0` 的收敛序列。
另外 Allen–Cahn 不守恒：本文用 `M = 0.005` 抑制液滴收缩（`M = 0.05` 时
松弛过程中 `a_eq / R` 会掉到 0.92）。

## 运行

```bash
conda activate afsi-dolfinx
cd afsic/demo/multiphase/demo_803_relaxation

python main.py                 # lambda = 1，约 4 min
python main.py --lam 2         # 黏度跳变，约 11 min
python main.py --sweep --plot  # 上表全部 + 松弛曲线图，约 21 min
```

结果写到 `output/relaxation.csv`（`--plot` 时另有 `output/relaxation.png`：
`D(t)` 对数图 + 解析 `D_0 e^{-t/tau}` 虚线）。
