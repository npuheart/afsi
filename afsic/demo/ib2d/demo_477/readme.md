# demo_477 — IB2d `Example_Concentration_Gradients/Bifurcating_Artery`（分叉动脉 + 被动标量）

IB2d 官方算例（`matIB2d/Examples/Example_Channel_Flow/Example_Concentration_Gradients/Bifurcating_Artery`）。
它是 demo_474（同一条分叉动脉、无标量）的 `concentration` 版本：**新机制**只是把
被动标量挂到已经移植过的"射流 + 钉死软壁"流动上。

## 算例内容

* `2 x 2` 周期盒、`mu = 0.1`、`rho = 1`、`128 x 128`、`dt = 5e-5`；
  官方 `T = 1.0`（20000 步、`print_dump = 200`）→ 本 demo 默认 `T = 0.1`（2000 步、11 帧）。
* **结构**：1144 个 `k = 1.25e7` 的钉死目标点描出一条 Y 形分叉动脉
  （`x in [0.075, 1.597]`、`y in [0.188, 1.812]`）。其中 3 对点**坐标重合**
  （分叉路口），需要用 demo_474 的小偏移技巧（`1e-6 h`）给它们各自的网格顶点。
* **射流**：算例自带 `please_Compute_External_Forcing.m`（已移植为同名 `.py`，
  两个代码共用）：窗口 `x in [0.1, 0.13]`、`y in [0.86, 1.14]`（34 个节点），

  ```
  Fx -= kStiff (uX - uX_tar),  uX_tar = -uMax 5 tanh(t) ((Lx/2+w/2)-y)((Lx/2-w/2)-y)
  ```

  `kStiff = 1e4`、`w = 0.3`、`uMax = 250`。注意两个括号里写的都是 `Lx`（`Lx = Ly = 2`，
  故本例无害），原样保留。
* **标量**：`artery.concentration` 首行 `kDiff = 5e-5`，其余为 `(Ny, Nx)` 初始浓度——
  入口射流正下游一个 `19 x 19` 方块（`x in [0.156, 0.438]`、`y in [0.859, 1.141]`，
  361 个非零节点，峰值 0.99957，节点值和 243.33）。

## 移植要点

1. **标量算子与 demo_476 完全相同**（`perform_Time_Split_Upwind`、周期 upwind/中心差分、
   `u^{n+1}`、节点网格），在 demo_476 中已被验证到 **1e-11**（浮点舍入）。
2. **`dt = 5e-5` 是官方值**，本例无需像 demo_474 那样减半（`k dt²/(ρh²) = 0.12`）。
3. **`GRAD_DIV = 1.0` 必须打开**（与 demo_474 同样的标定）：`gamma = 0` 时被驱动的射流比参考
   **大 1.5 倍**（比例随时间恒定，不是相位差），`gamma = 1.0` 把窗口 `max|u|` 差压到 2.66%。
4. 模板（`main.py`/`compare.py`）在 demo_473/474/476 基础上扩展：可选外力模块、
   可选标量场；`compare.py` 增加浓度剖面/场/历史图与 `max|dC|`、`relL2(C)`、峰值、总量指标。

## 结果

参考运行约 105 s、AFSI 运行约 93 s，各 11 帧（`t = 0 .. 0.10005`）。

| 指标（末帧 `t = 0.10005`） | 结果 |
|---|---|
| 标记点偏差（1144 点钉死） | 1.63e-4 m = **1.04e-2 h** |
| 施力窗口 `max\|u\|` AFSI / IB2d | 1.2292 / 1.2628（**2.66%**，与 demo_474 的 2.7% 一致） |
| 速度场相对 $L_2$ 误差（窄带外） | 5.52e-1 |
| 窄带外 `max\|du\|` | 5.69e-1 = 2.3e-1 `max\|u\|` |
| 罚力公式核对 | ≤7.85（`\|f\|_{\max}` 1.67e4，**0.05%**） |
| 浓度相对 $L_2$ 误差 | **4.80e-2** |
| 浓度 `max\|ΔC\|` | 1.82e-1（`max C` ≈ 0.993） |
| 峰值 `max C` AFSI / IB2d | 0.99305 / 0.99354（**4.9e-4** 相对） |
| 总量 `∑C` AFSI / IB2d（初值 243.33） | 242.27 / 246.82（相对差 1.84%） |

**能验证**：驱动机制（窗口 2.66%、罚力 0.05%）、软钉死结构（1.0e-2 h）、
以及**标量平流**——峰值与走位都对（峰值只差 4.9e-4）。

**已知限制（与 demo_474 同源）**：分叉后支管区的速度场不可比（窄带外相对 $L_2$ 误差 0.55、
中列流量连符号都不同）。这一族算例由**软目标点壁的"渗漏"**主导（`k = 1.25e7` 的钉死壁
并非严格不可穿透），两种代码的罚力/投影组合对渗漏的处理不同，属于移植的已知差异，
与本 demo 新增的标量机制无关。标量本身的 `relL2 = 4.8%` 正是这个速度差异的脚印：
算子在 demo_476 已被验证到 1e-11，且总量漂移两边**方向相反**（AFSI −0.4%、IB2d +1.4%，
分裂 upwind 格式本身并不严格守恒）。
