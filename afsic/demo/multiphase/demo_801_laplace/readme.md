# demo_801 — 静液滴：Laplace 定律 `dp = sigma / R`

两相流实现最经典的标定：**静止液滴**。半径 `R` 的圆形液滴放在静止方腔内（四壁无滑移），
没有重力、没有密度/黏度差（`rho_1 = rho_2`、`mu_1 = mu_2`），所以测到的压差**只**来自
表面张力、曲率和投影三者。平衡时

```
p_in - p_out = sigma * kappa = sigma / R        (二维, kappa = 1/R)
```

## 官方参照与设置

上游 IB2d 没有多相流算例，这里没有"官方数据"可对齐；**解析解就是参照**：

* 方腔 `[0,1]^2`，`R = 0.25`，`sigma = 1`，`mu = 0.05`，`rho = 1`。
* 相场：`phi(d) = 0.5 (1 - tanh(d / (2 sqrt(2) eps)))`，`d = |x - c| - R`，
  `eps = eps_factor * h`，`h = 1/NX`。
* 时间步默认取**毛细时间步上限**（Brackbill）的三折：
  `dt = 0.3 sqrt(rho h^3 / (2 pi sigma))`。
* `Tfinal = 0.08`（压差在几十步内即建立，之后只是寄生电流的稳态）。

## 移植 / 实现要点

见 [`../readme.md`](../readme.md) 的求解器说明。与验证直接相关的三点：

1. 曲率用**不分解形式**在网格上中心差分（`kappa = -(lap phi)/|grad phi| + ...`），
   并对相场和曲率各做 2 次欠松弛平滑。用 CG1 单元梯度直接算散度时，同一液滴的曲率
   是 `±35`（精确 4），几步就发散；本实现给出界面带上的 `3.95 ± 0.5`。
2. 压力用**齐次自然**边界 `(1/rho) dp/dn = 0`，不在压力方程里加边界通量项。
3. 压力**只出现在投影里**，预测步不含 `grad p`。

## 结果（`--sweep`，本机实测）

| NX | `eps/h` | `dt` | `dp` (测) | `sigma/R` | 相对误差 | `a_eq`（精确 0.25） | 寄生电流 `max\|u\|` | `Ca_parasitic` | 步数 | 用时 |
|---|---|---|---|---|---|---|---|---|---|---|
| 32 | 1.0 | 6.61e-4 | 3.8182 | 4.0 | **+4.55%** | 0.24494 | 9.8e-3 | 4.9e-4 | 121 | 1.2 s |
| 64 | 1.0 | 2.34e-4 | 4.0679 | 4.0 | **+1.70%** | 0.24825 | 9.6e-3 | 4.8e-4 | 343 | 14.5 s |
| 128 | 1.0 | 8.26e-5 | 4.0358 | 4.0 | **+0.89%** | 0.24953 | 6.4e-3 | 3.2e-4 | 968 | 173 s |
| 64 | 2.0 | 2.34e-4 | 3.8260 | 4.0 | +4.35% | 0.24825 | 3.0e-3 | 1.5e-4 | 343 | 15.4 s |
| 128 | 2.0 | 8.26e-5 | 4.0624 | 4.0 | +1.56% | 0.24953 | 2.7e-3 | 1.3e-4 | 968 | 154 s |
| 64 | 0.75 | 2.34e-4 | 4.0735 | 4.0 | +1.84% | 0.24825 | 1.4e-2 | 6.8e-4 | 343 | 13.3 s |

* 误差随网格**一阶**下降（4.55% → 1.70% → 0.89%，`eps = h`），与 CSF + 一阶投影的
  预期一致。
* `eps` 变宽（`2h`）时压差误差在粗网格上偏大、细网格上同阶，但寄生电流降低 3 倍
  （力被摊到更宽的带上）；`eps = 0.75h` 时压差仍准，寄生电流升到 1.4e-2。
  默认取 `eps = h`。
* `a_eq` 是由 `phi >= 0.5` 区域**面积**反推的等效半径，比 `R` 略小（`NX=128` 时 0.19%），
  这是**离散等高线**（节点多边形）的偏差，随 `h → 0` 收敛，不是物理误差。

**能验证**：表面张力 -> 压差这一整条链路（曲率、CSF 力、投影）在 `NX=128` 上到
**0.89%**，并给出干净的一阶收敛；`dp` 在几十步内就稳定（不是慢慢漂上去的）。

**不能验证 / 已知局限**：

* 残余速度（`max|u| ~ 1e-2`，`Ca_parasitic ~ 5e-4`）是 CSF 的**寄生电流**，
  不是物理流动；它随 `eps` 变宽而减小，随网格加密缓慢减小。它对 Laplace 定律的
  积分量没有影响（压差仍然准确），但如果要长时间追踪小 `Ca` 的形变（见 demo_802），
  它是误差来源之一。
* `a_eq`（面积法等效半径）有 ~0.2~2% 的离散偏差（见上表）。
* 界面宽度是模型参数：`4 eps` 的界面厚度不能小于格子尺度，本实现取 `eps >= 0.75h`。

## 运行

```bash
conda activate afsi-dolfinx
cd afsic/demo/multiphase/demo_801_laplace

python main.py                    # 64x64, eps = h        ~15 s
python main.py --nx 128           # 加密                  ~3 min
python main.py --sweep --plot     # 上表全部 + 压力剖面图  ~6 min
```

结果写到 `output/laplace.csv`（`--plot` 时另有 `output/laplace_profile.png`：
穿过液滴中心的一条压力/相场剖面，虚线为精确界面半径 `R`）。
