# demo_460 — IB2d `Pulsing_Heart` (prescribed-motion heart pump)

IB2d 官方算例（`matIB2d/Examples/Example_Pulsing_Heart/32x32`）在 AFSI 中的复现。
这是**数据文件驱动的移动目标点**算例：384 个目标点的锚点按心脏收缩/舒张的
两相多项式规律在**两条预设形线之间插值**。

## 算例内容

`1 x 1` 周期盒、`mu = 0.5`、`rho = 1`、`32 x 32`、`dt = 1e-5`、`T = 0.1`（10000 步）。
结构是一条 **384 点心脏轮廓**（无弹簧、无梁），每个点都是 `k = 1e8` 的目标点。

锚点位置由算例的 `update_Target_Point_Positions.m` 给出：从
`All_Positions.txt` 读入两条形线（第 1–2 列 = 舒张态 $P_1$，第 3–4 列 = 收缩态
$P_2$），在周期 `tP1 + tP2 = 0.05 s` 内按两相多项式插值

| 相位 | 规律 |
|---|---|
| `t <= tP1` | $X = P_1 + g(t/tP1)\,(P_2 - P_1)$ |
| `t > tP1` | $X = P_2 + g((t-tP1)/tP2)\,(P_1 - P_2)$ |
| $g(s)$ | $s<0.1$：$a s^2$；$0.1\le s<0.9$：$c s^3+d s^2+g s+h$；$s\ge0.9$：$-b(s-1)^2+1$ |

（$a=b=2.7397$、$c=-2.0294$、$d=3.0441$、$g=-0.015221$、$h=2.5368\times10^{-4}$）。
$T=0.1$ s 内心脏**收缩–舒张两个完整周期**，锚点行程最大 **0.119 m = 3.81 h**
（h = 1/32）。插值规律是**无状态**的（只取决于 `t mod 0.05`），与 demo_459 的
逐步累加规律不同，且 384 个锚点各有自己的轨迹。

> 上游小细节：三段多项式只在**函数值**上"基本连续"——在 $s=0.1$ 与 $s=0.9$
> 两处实际存在 $h$ 大小的跳变，映射到锚点上就是 $h\,(P_2-P_1) \approx 3\times10^{-5}$ m
> 的位置跳变。两侧实现都逐字照搬（AFSI 的锚点与 `.m` 递推**逐位一致**，误差 0.0）。
> 由于该跳变依赖于分支判据，`compare.py` 重建规律时使用与 pyIB2d 相同的
> **累加时钟**（`current_time += dt`）而不是 `(step+1)*dt`。

## 结果

参考运行 19.8 s、AFSI 运行 46.6 s，两边各 201 帧（`python compare.py` 生成
`figures/`）：

| 指标 | 结果 |
|---|---|
| 目标点递推 | AFSI 锚点与 `.m` 递推 **逐位一致**（误差 0.0） |
| 形状质心 | 最大偏差 **5.1e-6 m**；收缩–舒张相位完全同步 |
| 包围面积 | 预设轮廓 0.126782–0.272723；最大偏差 AFSI **7.1e-4**、IB2d 2.9e-3（都跟着预设面积走） |
| 标记点偏差 | 典型 **1.21e-2 m = 0.39 h**，最大 1.93e-2 m = 0.62 h |
| 标记点-锚点滞后 | AFSI 中位 3.5e-3 / 最大 5.4e-3 m；IB2d 中位 1.2e-2 / 最大 1.95e-2 m |
| 速度场 | 全程 `max|u|` AFSI **111** / IB2d **341** m/s（预设膜速度峰值 ~7 m/s），末帧 `max|Δu|` 61 m/s |

### 关于 1e-2 m 量级的标记点偏差

心脏是**运动学被完全指定**的结构，两个求解器都靠 `k = 1e8` 的罚力把膜拉向锚点，
因此膜的稳态误差 $\delta$（滞后）是"罚力柔度"量级。两侧的 $\delta$ 不同
（AFSI 中位 3.5e-3 vs 参考 1.2e-2 m），标记点互差主要就是这个**滞后之差**，
而不是时间/相位失配或病态失稳。证据：

1. **不是参考的时间步不足**：参考在 `dt/2`（20000 步）下标记点仅变化
   ≤ 3.2e-3 m（中位 2.5e-5 m），而 AFSI–参考之差（中位 1.21e-2 m）几乎不变。
   复现：`python run_reference.py --dt 5e-6 --print-dump 100 --out /tmp/ref_halfdt.npz --run /tmp/run_halfdt`
2. **不是时间对齐**：两侧帧按同一步数对齐（见"移植要点"），且 1 步错位在此算例
   只值 7e-5 m。
3. **偏差随罚力柔度同步缩放**：把两侧的 $k$ 同时降 10 倍（`K_SCALE=0.1`、
   `--k-scale 0.1`），AFSI 的滞后中位 3.5e-3 → 9.9e-3 m，标记点互差中位
   1.21e-2 → 2.90e-2 m（同向放大），而质心偏差仍只有 3e-5 m。
4. 两侧的"滞后"与"伪速度"都随搏动相位同步起伏（AFSI 幅值约小 3.5 倍）。

因此本算例的结论是：**运动学（锚点规律、质心、包围面积、相位）精确复现**，而
膜上逐点位置的一致性受限于上游 `k = 1e8` 硬化罚力在显式格式下的柔度差
（该算例本身 `max|u|` 达 341 m/s，速度场只能在滤波意义下比较）。

## 移植要点

1. `matIB2d` 的 1-based 文件 → `ib2d_io.load_example(..., index_base=1)` 重编号，
   `run_reference.py` 写出重编号后的 `.target`。
2. 参考运行目录还需 `All_Positions.txt`（`.m` 的 Python 移植从运行目录读取；
   移植里对该文件做了缓存，否则 10000 步都花在文本解析上）。
3. 输出帧与 pyIB2d 落在**同一步**（pyIB2d 的第 $k$ 帧是第 `k·print_dump+1` 步的状态，
   时间戳却写 `k·print_dump·dt`，属上游约定），AFSI 按同样的步输出并记录真实时间。
4. 结构用**闭合**零刚度 FE 链承载 384 个标记点自由度（demo_459 是开放链）。

## 运行

```bash
conda activate afsi-dolfinx
python run_reference.py          # pyIB2d 参考 -> ib2d_reference.npz（~20 s）
python main.py                   # AFSI        -> plot/afsi_result.npz（~47 s）
python compare.py                # 对比 + figures/
```

环境变量：`TFINAL`、`DT`、`NX`、`PRINT_DUMP`、`GRAD_DIV`、`K_SCALE`、`OUTPUT_PATH`；
参考脚本选项：`--tend`、`--dt`、`--print-dump`、`--k-scale`、`--out`、`--run`。
`TFINAL=0.001 python main.py` 可做 smoke test。
