# demo_471 — IB2d `Example_Aneurysm`（弹性瘤壁 + 任意外力）

IB2d 官方算例（`matIB2d/Examples/Example_Channel_Flow/Example_Aneurysm`）的复现，
是 `arb_ext_force` 与**弹簧 + 不变梁 + 目标点子集**组合的第一个算例。

## 算例内容

* `1 x 1` 周期盒、`mu = 0.1`、`rho = 1`、`64 x 64`、`dt = 1e-4`、`T = 0.25`（2500 步）。
* **结构**：116 个标记点——两条壁（`y = 0.4 / 0.6`，下层壁带 13 点内凹鼓包），其中
  **101 点是 `k = 1e7` 的钉死目标点**；上层壁中段 15 个标记点**不钉死**，仅由
  16 根弹簧（`k = 5e5`、静长 `ds = 1/64`）与 15 根不变梁（`kb = 5e5`、`C = 0`）连接，
  这就是可变形的"动脉瘤"补片。
* **外力**：`x in [0.1, 0.16]`、`y in [0.41, 0.59]`，

  $$u_x^{\rm tar} = -u_{\max}\,10|\sin(10\pi t)|\,(\tfrac{L_x}{2}+\tfrac{W}{2}-y)(\tfrac{L_x}{2}-\tfrac{W}{2}-y),$$

  `k = 1e4`、`u_max = 250`——注意振幅是 demo_467 的 **10 倍**（`u^tar` 峰值 25 m/s），
  `mu = 0.1` ⇒ 单元 $Re \approx 4$，网格无法分辨这些速度。

## 结果

参考运行 ~100 s、AFSI 运行 ~35 s，各 26 帧。

| 指标（末帧 `t = 0.25`） | 结果 |
|---|---|
| **钉死**标记点偏差（101 点） | 7.0e-4 m = **4.5e-2 h**（钉死约束被正确复现） |
| 施力窗口 `max\|u\|` AFSI / IB2d | 24.13 / 24.29（**0.65%**） |
| 流量（中列、窗口行）相对差 | **0.87%** |
| 罚力公式核对 | ≤2.96e1（`\|f\|_{\max}` 1.75e4，0.17%） |
| **自由**补片 15 点偏差 | 0.80 m = 5.1e1 h ✗ |

**自由补片为何不可复现（已定位，非移植错误）**：本例把 25 m/s 的目标速度强加在
`mu = 0.1`、`h = 1/64` 的流体上（单元 $Re \approx 4$），而固定补片的弹簧力
（`k\,ds\,dt \approx 0.08` 每步）远不足以抵抗该射流，因此补片被整体卷走；这是
一个**时间步敏感、网格不可分辨**的暴力工况：

* 原样 `dt = 1e-4` 时，IB2d 参考的自由补片**自己跑飞**（15 个点散落到
  `x = 0.03 ... 0.99`、`y = 0.07 ... 0.89` 各处），而 AFSI 的补片仍是一个连贯的拱形
  （`y = 0.619 ... 0.707`）；两边 `max|u|` 逐帧在 7 ↔ 24 m/s 之间剧烈振荡；
* `dt` 减半（`dt = 5e-5`、`T = 0.045`）后**两边都保持连贯拱形**，形状一致，
  拱顶高度 AFSI 0.709 / IB2d 0.746（差 0.037 m = 2.4 h）；
* 全程"驱动力"量始终一致：窗口 `max|u|` 0.43%（dt/2）、流量 2.4%（dt/2）、
  钉死标记点 ≤4.5e-2 h、罚力公式 ≤0.17%。

结论：`arb_ext_force` + 弹簧/梁/目标点子集这套机制移植正确（驱动力与钉死约束逐项吻合），
但**本算例按原样发布时的自由补片轨迹在任何两个不同实现（甚至同一实现的 dt/2）之间
都不可点对点比较**；readme 明确记录这一点而不是用"看起来接近"掩盖。
（另注：IB2d 弹簧/梁力在跨周期边界处有最小镜像分支，本移植已按原样实现，
`compare.py` 的对照表明该分支在本算例中并非差异来源。）

## 运行

```bash
conda activate afsi-dolfinx
python run_reference.py                  # pyIB2d 参考（~100 s）
python main.py                           # AFSI（~35 s）
python compare.py

# dt/2 交叉核对（T 缩短到 0.05，compare.py 会自动配对）
python run_reference.py --dt 5e-5 --tend 0.05 --print-dump 100 \
    --out ib2d_reference_dt5e-5.npz --run ib2d_run_dt5e-5
DT=5e-5 TFINAL=0.05 PRINT_DUMP=100 OUTPUT_PATH=./plot_dt5e-5 python main.py
```
